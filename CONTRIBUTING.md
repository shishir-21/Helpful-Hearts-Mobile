# Contributing

## Branching

Use small feature branches such as `feat/auth-login`, `feat/doctor-search`, and `fix/appointment-slot-race`.

## Commits

Use Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`.

## Rules

- TypeScript strict mode stays enabled.
- Never commit secrets or health data.
- Keep business logic inside feature modules.
- Add tests for business-critical behavior.
- Keep each phase runnable before moving forward.
